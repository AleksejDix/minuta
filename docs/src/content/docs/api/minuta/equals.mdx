Check whether two periods are identical: the same unit, the same start and
the same end. Like Temporal's `equals()`, the calendar and the time zone
count too.

```ts
import { equals } from "@aleksejdix/minuta";
```

```ts
equals(first, second);
```

## Example

```ts
import { equals, month, period } from "@aleksejdix/minuta";

const march = month(Temporal.PlainDate.from("2026-03-15"));

equals(march, month(Temporal.PlainDate.from("2026-03-31"))); // → true
equals(march, period(march.start, march.end)); // → false: a month and a custom period
```

## Parameters

| Name     | What it is        |
| -------- | ----------------- |
| `first`  | One period.       |
| `second` | The other period. |

## Returns

`true` when both periods have the same `unit`, and their starts and their
ends are equal values, otherwise `false`.

## The same values, not the same time

Dates are equal when they are the same date in the same calendar. Moments
are equal when they are the same instant in the same time zone and
calendar, as `Temporal.ZonedDateTime#equals` checks. So two hours that start
at the same instant in different zones are not equal:

```ts
const zurich = hour(
  Temporal.ZonedDateTime.from("2026-03-16T10:00[Europe/Zurich]")
);
const utc = hour(Temporal.ZonedDateTime.from("2026-03-16T09:00[UTC]"));

equals(zurich, utc); // → false, different zones
compare(zurich, utc); // → 0, the same time
```

A day of dates and the hours of that day are never equal: one holds dates,
the other moments.

To ask whether the two cover the same time, use [`compare`](../compare/):
it returns `0`.

## Identical, or in the same week

`equals` checks the whole period. To check whether two periods fall in the
same day, week or month, compare the units around their starts:

```ts
const monday = day(Temporal.PlainDate.from("2026-03-16"));
const friday = day(Temporal.PlainDate.from("2026-03-20"));

equals(week(monday.start), week(friday.start)); // → true
equals(monday, friday); // → false
```

This looks at the starts only: a week that starts in March is in March by
`equals(month(w.start), month(date))`, even when it ends in April. For a
unit held in a variable, use a bound object:
`equals(time[unit](a.start), time[unit](b.start))`, with
`time = withUnits(createUnits())`.

## Errors

`equals` does not throw. It needs no units.
