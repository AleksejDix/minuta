Check whether two periods fall in the same day, week, month or year: are
Monday and Friday in the same week, are these two appointments on the same
day.

```ts
import { same } from "@aleksejdix/minuta";
```

```ts
same(first, second, unit);
```

## Example

```ts
import { period, same } from "@aleksejdix/minuta";

const monday = period(Temporal.PlainDate.from("2026-03-16"), "day");
const friday = period(Temporal.PlainDate.from("2026-03-20"), "day");

same(monday, friday, "week"); // → true
same(monday, friday, "day"); // → false
```

## Parameters

| Name     | What it is                                                       |
| -------- | ---------------------------------------------------------------- |
| `first`  | One period.                                                      |
| `second` | The other period.                                                |
| `unit`   | How coarse to compare: `"year"`, `"month"`, `"week"`, `"day"`, … |

## Returns

`true` when both periods _start_ in the same `unit`, otherwise `false`.

The two periods may have any units of their own. A day and an hour can be
compared by day; a day and a year by year:

```ts
same(
  period(Temporal.PlainDate.from("2026-06-01"), "year"),
  period(Temporal.PlainDate.from("2026-12-31"), "day"),
  "year"
);
// → true
```

## Only the starts are compared

`same` looks at where each period starts and ignores where it ends. The week
from Mon Mar 30 to Sun Apr 5 starts in March, so it counts as March, even
though most of it is in April:

```ts
const week = period(Temporal.PlainDate.from("2026-03-31"), "week");

same(week, period(Temporal.PlainDate.from("2026-03-01"), "month"), "month"); // → true
same(week, period(Temporal.PlainDate.from("2026-04-01"), "month"), "month"); // → false
```

## Weeks start on Monday

Saturday and Sunday are in the same week here, because weeks run Monday to
Sunday. Sunday and the Monday after are not:

```ts
same(
  period(Temporal.PlainDate.from("2026-03-22"), "day"),
  period(Temporal.PlainDate.from("2026-03-23"), "day"),
  "week"
);
// → false, Sun Mar 22 and Mon Mar 23
```

With weeks that start on Sunday, Saturday and Sunday are in different weeks.
Take `same` from [`withUnits`](../with-units/) for that:

```ts
import { createUnits, period, withUnits } from "@aleksejdix/minuta";

withUnits(createUnits({ weekStartsOn: "sunday" })).same(
  period(Temporal.PlainDate.from("2026-03-21"), "day"),
  period(Temporal.PlainDate.from("2026-03-22"), "day"),
  "week"
);
// → false, Sat Mar 21 and Sun Mar 22
```

## Identical periods: `equals`

`same` takes a real unit. To check that two periods are identical, the same
unit with the same start and end, use [`equals`](../equals/):

```ts
const wholeDay = period(Temporal.PlainDate.from("2026-03-16"), "day");
const firstHour = period(
  Temporal.ZonedDateTime.from("2026-03-16T00:00[Europe/Zurich]"),
  "hour"
);

same(wholeDay, firstHour, "day"); // → true, same day
equals(wholeDay, firstHour); // → false, different units and ends
```

## Errors

`same` throws a `RangeError` whose message starts with a code:

| Code                 | When                                            |
| -------------------- | ----------------------------------------------- |
| `UNIT_NOT_SUPPORTED` | `unit` is not a known unit, e.g. `"fortnight"`. |
