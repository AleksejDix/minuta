Get the quarter of the year that a date or a moment falls in: three months,
Q1 from January, Q2 from April, Q3 from July, Q4 from October.

```ts
import { quarter } from "@aleksejdix/minuta";
```

```ts
quarter(value);
```

## Example

```ts
import { quarter } from "@aleksejdix/minuta";

quarter(Temporal.PlainDate.from("2026-05-15"));
// → { start: 2026-04-01, end: 2026-07-01, unit: "quarter" }: Q2, April to June
```

## Parameters

| Name    | What it is                                                      |
| ------- | --------------------------------------------------------------- |
| `value` | A `PlainDate` or a `ZonedDateTime` anywhere inside the quarter. |

## Returns

A `DatePeriod` with the unit `"quarter"`: `start` is the first day of the
quarter's first month, `end` the first day of the next quarter. The end is
excluded.

[`toLocaleString`](../to-locale-string/) names a quarter by the month it
starts in, "Apr 2026"; format `period(q2.start, q2.end)` to show both ends.

## Other calendars

In every calendar, a year has four quarters of three months. In a year
with 13 months, the extra month joins a quarter: in a Hebrew leap year,
Adar I joins the second quarter, which then runs from Tevet to Adar II.
See [Quarters in years with 13 months](../../../concepts/calendar-systems/#quarters-in-years-with-13-months).

## Errors

The main entry's `quarter` does not throw for a date or a moment. From
[`withUnits`](../with-units/), units without a `quarter` spec give
`UNIT_NOT_SUPPORTED`.
