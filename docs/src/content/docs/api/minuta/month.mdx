Get the whole month that a date or a moment falls in: 28 to 31 days, with
no day arithmetic.

```ts
import { month } from "@aleksejdix/minuta";
```

```ts
month(value);
```

## Example

```ts
import { month } from "@aleksejdix/minuta";

const march = month(Temporal.PlainDate.from("2026-03-15"));
// → { start: 2026-03-01, end: 2026-04-01, unit: "month" }
```

Name the result after what it holds, `march` here: `const month =
month(date)` cannot work, `month` is already the function.

Any date in March gives the same month: Mar 1, Mar 15 and Mar 31 at 23:59.

## Parameters

| Name    | What it is                                                    |
| ------- | ------------------------------------------------------------- |
| `value` | A `PlainDate` or a `ZonedDateTime` anywhere inside the month. |

## Returns

A `DatePeriod` with the unit `"month"`: `start` is the month's first day,
`end` the first day of the next month. The end is excluded, so March ends at
Apr 1, where April starts. A moment's month is the month of its date in its
own zone.

## Other calendars

A month follows the calendar of the date, or the `calendar` of the units:

```ts
import { createUnits, withUnits } from "@aleksejdix/minuta";

const hijri = withUnits(createUnits({ calendar: "islamic-umalqura" }));
hijri.month(Temporal.PlainDate.from("2026-03-18"));
// → Ramadan 1447: { start: 2026-02-18[u-ca=islamic-umalqura], end: 2026-03-20[…], unit: "month" }

const hebrew = withUnits(createUnits({ calendar: "hebrew" }));
hebrew.month(Temporal.PlainDate.from("2027-03-01"));
// → Adar I 5787, the leap month: { start: 2027-02-08[u-ca=hebrew], end: 2027-03-10[…], unit: "month" }
```

See [Calendar systems](../../../concepts/calendar-systems/).

## Errors

The main entry's `month` does not throw for a date or a moment. From
[`withUnits`](../with-units/), units without a `month` spec give
`UNIT_NOT_SUPPORTED`.
