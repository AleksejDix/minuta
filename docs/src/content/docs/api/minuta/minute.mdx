Get the whole minute that a moment falls in.

```ts
import { minute } from "@aleksejdix/minuta";
```

```ts
minute(value);
```

## Example

```ts
import { minute } from "@aleksejdix/minuta";

minute(Temporal.ZonedDateTime.from("2026-03-18T10:30:45[Europe/Zurich]"));
// → { start: 2026-03-18T10:30+01:00[Europe/Zurich], end: 2026-03-18T10:31+01:00[…], unit: "minute" }
```

## Parameters

| Name    | What it is                                                                  |
| ------- | --------------------------------------------------------------------------- |
| `value` | A `ZonedDateTime` inside the minute, or a `PlainDate` for its first minute. |

## Returns

A `TimePeriod` with the unit `"minute"`: `start` and `end` are
`ZonedDateTime`s in the value's zone, one minute apart. The end is excluded.
A `PlainDate` starts at the beginning of its day in the units' time zone,
as for [`hour`](../hour/).

## Errors

The main entry's `minute` does not throw for a date or a moment. From
[`withUnits`](../with-units/), units without a `minute` spec give
`UNIT_NOT_SUPPORTED`.

## Related
