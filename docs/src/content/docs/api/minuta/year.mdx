Get the whole year that a date or a moment falls in.

```ts
import { year } from "@aleksejdix/minuta";
```

```ts
year(value);
```

## Example

```ts
import { year } from "@aleksejdix/minuta";

year(Temporal.PlainDate.from("2026-03-15"));
// → { start: 2026-01-01, end: 2027-01-01, unit: "year" }
```

## Parameters

| Name    | What it is                                                   |
| ------- | ------------------------------------------------------------ |
| `value` | A `PlainDate` or a `ZonedDateTime` anywhere inside the year. |

## Returns

A `DatePeriod` with the unit `"year"`: `start` is the year's first day,
`end` the first day of the next year. The end is excluded. A moment's year
is the year of its date in its own zone.

## Other calendars

A year follows the calendar of the date, or the `calendar` of the units.
A Hebrew leap year has 13 months:

```ts
import { createUnits, withUnits } from "@aleksejdix/minuta";

const hebrew = withUnits(createUnits({ calendar: "hebrew" }));
const leapYear = hebrew.year(Temporal.PlainDate.from("2027-03-01"));
// → { start: 2026-09-12[u-ca=hebrew], end: 2027-10-02[u-ca=hebrew], unit: "year" }, 5787

hebrew.count(leapYear, "month"); // → 13
```

See [Calendar systems](../../../concepts/calendar-systems/).

## Errors

The main entry's `year` does not throw for a date or a moment. From
[`withUnits`](../with-units/), units without a `year` spec give
`UNIT_NOT_SUPPORTED`.
