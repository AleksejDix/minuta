Get the whole weeks that cover a year: from the week that contains January 1
to the week that contains December 31.

```ts
import { yearGrid } from "@aleksejdix/minuta";
```

```ts
yearGrid(value);
```

## Example

```ts
import { yearGrid } from "@aleksejdix/minuta";

const grid = yearGrid(Temporal.PlainDate.from("2026-06-01"));

grid.periods.length; // → 53
grid.periods[0]; // → { start: 2025-12-29, end: 2026-01-05, unit: "week" }
grid.periods[52]; // → { start: 2026-12-28, end: 2027-01-04, unit: "week" }
grid.yearStart; // → 2026-01-01
grid.weekStartsOn; // → 1 (Monday)
```

## Parameters

| Name    | What it is                                   |
| ------- | -------------------------------------------- |
| `value` | Any date or moment inside the year you want. |

## Returns

An object with three fields:

- `periods` — the weeks, in order. Each one is a whole week with the unit
  `"week"`: `start` is its first day, `end` the first day of the next week.
- `yearStart` — the first day of the year as a `PlainDate`, e.g. 2026-01-01.
- `weekStartsOn` — the first day of the week as a number: 0 = Sunday,
  1 = Monday … 6 = Saturday.

The weeks are never cut. The first week usually starts in December of the
year before, and the last one usually ends in January of the next year. If
you need the days of the year only, use [`divide`](../divide/)
instead.

## 53 or 54 weeks

A year has 365 or 366 days, which is a bit more than 52 weeks. So the grid
always has at least 53 weeks. A leap year that starts on the last day of the
week needs 54:

```ts
const jan1 = Temporal.PlainDate.from("2012-01-01");

yearGrid(jan1).periods.length;
// → 54 (2012 starts on a Sunday, weeks start on Monday)

withUnits(createUnits({ weekStartsOn: "sunday" })).yearGrid(jan1).periods
  .length;
// → 53
```

Both grids of 2012 under the year. With Monday weeks, the first week holds
only Sunday Jan 1 of 2012, and the grid needs one more week at the end:

<Timeline
  caption="2012 has 366 days and starts on a Sunday: 54 Monday weeks, but 53 Sunday weeks."
  tracks={[
    { label: "2012", periods: [year2012], tone: "muted" },
    {
      label: "Monday weeks",
      periods: yearGrid(plainDate("2012-01-01")).periods,
      tone: "accent",
    },
    {
      label: 'weekStartsOn: "sunday"',
      periods: withUnits(createUnits({ weekStartsOn: "sunday" })).yearGrid(
        plainDate("2012-01-01")
      ).periods,
      tone: "ink",
    },
  ]}
/>

Do not use the position in `periods` as a week number. The first week of the
grid is the week that contains January 1, which is not always week 1 in the
ISO 8601 system: Jan 1 2021 was a Friday, so the grid starts on Mon Dec 28
2020, which ISO counts as week 53 of 2020. minuta does not compute week
numbers.

## Week start

The weeks start on Monday here. For another week start, take `yearGrid`
from [`withUnits`](../with-units/):

```ts
import { createUnits, withUnits } from "@aleksejdix/minuta";

const grid = withUnits(createUnits({ weekStartsOn: "sunday" })).yearGrid(
  Temporal.PlainDate.from("2026-06-01")
);

grid.periods[0]; // → { start: 2025-12-28, end: 2026-01-04, unit: "week" }
grid.periods[52]; // → { start: 2026-12-27, end: 2027-01-03, unit: "week" }
```

## Errors

`yearGrid` from `withUnits(units)` throws a `RangeError` starting with
`UNIT_NOT_SUPPORTED` when `units` has no `year` or `week`.
