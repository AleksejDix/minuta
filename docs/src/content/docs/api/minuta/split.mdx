Cut a period in two at a date or moment: the part before it, and the part
from it on.

```ts
import { split } from "@aleksejdix/minuta";
```

```ts
split(period, at);
```

## Example

```ts
import { period, split } from "@aleksejdix/minuta";

const march = period(Temporal.PlainDate.from("2026-03-01"), "month");

split(march, Temporal.PlainDate.from("2026-03-15"));
// → [
//     { start: 2026-03-01, end: 2026-03-15, unit: "custom" },
//     { start: 2026-03-15, end: 2026-04-01, unit: "custom" },
//   ]
```

## Parameters

| Name     | What it is                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `period` | The period to cut.                                                                                                           |
| `at`     | Where the second part starts: a `PlainDate` for a date period, a `ZonedDateTime` for a time period. Must be inside `period`. |

## Returns

A pair of periods:

1. From the start of `period` to `at`.
2. From `at` to the end of `period`.

The first part ends where the second begins, and the end is excluded, so
every moment of `period` is in exactly one of the two. Both parts have the
unit `"custom"`: half a month is not a month.

`undefined` when `at` cannot cut the period.

## Where you can cut

`at` must lie strictly between the start and the end:

```ts
split(march, Temporal.PlainDate.from("2027-01-01"));
// → undefined (outside March)

split(march, Temporal.PlainDate.from("2026-03-01"));
// → undefined (at the start: the first part would be empty)

split(march, Temporal.PlainDate.from("2026-04-01"));
// → undefined (at the end: the second part would be empty)
```

Cutting at the last day works. The second part is then that one day:

```ts
split(march, Temporal.PlainDate.from("2026-03-31"));
// → [2026-03-01 – 2026-03-31, 2026-03-31 – 2026-04-01]
```

## Putting it back together

`merge` joins the parts again and can give the unit back:

```ts
import { merge } from "@aleksejdix/minuta";

merge(split(march, Temporal.PlainDate.from("2026-03-15")), "month");
// → { start: 2026-03-01, end: 2026-04-01, unit: "month" }
```

## Errors

`split` throws a `TypeError` when `at` is not of the period's kind, such as
a `ZonedDateTime` for a date period.
