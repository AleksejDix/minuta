Get the whole week that a date or a moment falls in: seven days from the
week's first day.

```ts
import { week } from "@aleksejdix/minuta";
```

```ts
week(value);
```

## Example

```ts
import { week } from "@aleksejdix/minuta";

week(Temporal.PlainDate.from("2026-03-18"));
// → { start: 2026-03-16, end: 2026-03-23, unit: "week" }: Monday to Sunday
```

## Parameters

| Name    | What it is                                                   |
| ------- | ------------------------------------------------------------ |
| `value` | A `PlainDate` or a `ZonedDateTime` anywhere inside the week. |

## Returns

A `DatePeriod` with the unit `"week"`: `start` is the week's first day,
`end` the first day of the next week. The end is excluded. A week can cross
a month or a year: the week of Jan 1 2026 runs from Mon Dec 29 2025.

## The week start

The main entry's weeks start on Monday (ISO 8601). For another first day,
bind the units with [`withUnits`](../with-units/): set `weekStartsOn`, or
let a `locale` choose.

```ts
import { createUnits, withUnits } from "@aleksejdix/minuta";

const date = Temporal.PlainDate.from("2026-03-18");

withUnits(createUnits({ weekStartsOn: "sunday" })).week(date);
// → { start: 2026-03-15, end: 2026-03-22, unit: "week" }

withUnits(createUnits({ locale: "ar-EG" })).week(date);
// → { start: 2026-03-14, end: 2026-03-21, unit: "week" }: from Saturday

withUnits(createUnits({ locale: "de-CH" })).week(date);
// → { start: 2026-03-16, end: 2026-03-23, unit: "week" }: from Monday
```

## Errors

The main entry's `week` does not throw for a date or a moment. From
[`withUnits`](../with-units/), units without a `week` spec give
`UNIT_NOT_SUPPORTED`.
