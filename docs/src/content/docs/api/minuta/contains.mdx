Check whether a date, a moment, or a whole other period lies inside a period: is this
appointment in March, is this day in this week.

```ts
import { contains } from "@aleksejdix/minuta";
```

```ts
contains(period, target);
```

## Example

```ts
import { contains, period } from "@aleksejdix/minuta";

const march = period(Temporal.PlainDate.from("2026-03-01"), "month");

contains(march, Temporal.PlainDate.from("2026-03-20"));
// → true

contains(march, period(Temporal.PlainDate.from("2026-04-01"), "day"));
// → false, Apr 1 is outside March
```

## Parameters

| Name     | What it is                                                             |
| -------- | ---------------------------------------------------------------------- |
| `period` | The outer period.                                                      |
| `target` | What to look for: a `PlainDate`, a `ZonedDateTime`, or another period. |

## Returns

`true` or `false`.

- For a moment: `true` when it is at or after `period.start` and before
  `period.end`.
- For a date: the date counts as its whole day, so it must lie fully inside.
- For a period: `true` only when the _whole_ target lies inside. A target that
  sticks out on either side gives `false`, even if most of it is inside. Use
  [`overlaps`](../overlaps/) to ask "do they share any time?".

A period contains itself. Next to a period of moments, a date becomes moments
in that period's time zone. For a `PlainDateTime`, give it a zone first, e.g.
`dateTime.toZonedDateTime("Europe/Zurich")`.

## The end is excluded

`start` is part of the period, `end` is not. March ends at Apr 1, so Apr 1 is
outside:

```ts
contains(march, march.start); // → true, Mar 1
contains(march, march.end); // → false, Apr 1
contains(march, Temporal.ZonedDateTime.from("2026-03-31T23:59[Europe/Zurich]")); // → true
```

## Partly inside is not inside

The week from Mon Mar 30 to Sun Apr 5 starts in March but ends in April:

```ts
import { contains, overlaps, period } from "@aleksejdix/minuta";

const week = period(Temporal.PlainDate.from("2026-03-31"), "week");

contains(march, week); // → false
overlaps(march, week); // → true
```

## The unit does not matter

`contains` only compares values. It works the same for months, custom
[`range`](../range/)s and pieces from [`divide`](../divide/), and it needs no
units.
