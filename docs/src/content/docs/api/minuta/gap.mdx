Get the free time between two periods, such as the break between two
meetings or the days between two bookings.

```ts
import { gap } from "@aleksejdix/minuta";
```

```ts
gap(first, second);
```

## Example

```ts
import { day, gap } from "@aleksejdix/minuta";

gap(
  day(Temporal.PlainDate.from("2026-03-02")),
  day(Temporal.PlainDate.from("2026-03-05"))
);
// → { start: 2026-03-03, end: 2026-03-05, unit: "custom" }
```

## Parameters

| Name     | What it is        |
| -------- | ----------------- |
| `first`  | One period.       |
| `second` | The other period. |

Both are periods. For a single date, pass its day: `day(date)`.
You can mix a period of dates and a period of moments: next to moments, the
dates become moments in their zone.

## Returns

The period between the two: it starts where the earlier one ends and ends
where the later one starts. Its unit is always `"custom"`.

`undefined` when there is no time between them: they touch or overlap.

## Order does not matter

`gap` finds out which one comes first:

```ts
gap(
  day(Temporal.PlainDate.from("2026-03-05")),
  day(Temporal.PlainDate.from("2026-03-02"))
);
// → { start: 2026-03-03, end: 2026-03-05, unit: "custom" }, the same as above
```

## Touching or overlapping periods have no gap

Mar 2 ends where Mar 3 starts. Nothing lies between them:

```ts
gap(
  day(Temporal.PlainDate.from("2026-03-02")),
  day(Temporal.PlainDate.from("2026-03-03"))
);
// → undefined (they touch)

gap(
  day(Temporal.PlainDate.from("2026-03-02")),
  month(Temporal.PlainDate.from("2026-03-01"))
);
// → undefined (March contains Mar 2)
```

## Dates and moments

`gap` takes periods only. Turn a date into its day, as in the example
above, or a moment into its hour, with [`hour`](../hour/):

```ts
gap(
  hour(Temporal.ZonedDateTime.from("2026-03-02T09:00[Europe/Zurich]")),
  hour(Temporal.ZonedDateTime.from("2026-03-02T12:00[Europe/Zurich]"))
);
// → 10:00 – 12:00 (the hour from 9:00 ends at 10:00)
```

To measure a gap, pass it to `count`, e.g.
`count(gap(a, b), "minute")`.
