Get the period right before a period: the day before a day, the week before
a week, the month before a month.

```ts
import { previous } from "@aleksejdix/minuta";
```

```ts
previous(period);
```

## Example

```ts
import { month, previous } from "@aleksejdix/minuta";

const march = month(Temporal.PlainDate.from("2026-03-15"));

previous(march);
// → { start: 2026-02-01, end: 2026-03-01, unit: "month" }
```

## Parameters

| Name     | What it is                                       |
| -------- | ------------------------------------------------ |
| `period` | The current period, e.g. a month from `month()`. |

## Returns

A new period of the same unit that ends where `period` starts:
`previous(march).end` equals `march.start`. It is a whole unit, with its own
length: before March (31 days) comes February (28 days in 2026).

`previous(p)` is the same as [`shift(p, -1)`](../shift/).

## Across years and clock changes

The previous period is found on the calendar, so it crosses year ends and
daylight-saving changes without surprises:

```ts
previous(year(Temporal.PlainDate.from("2026-03-18")));
// → { start: 2025-01-01, end: 2026-01-01, unit: "year" }

previous(day(Temporal.PlainDate.from("2026-03-30")));
// → { start: 2026-03-29, end: 2026-03-30, unit: "day" } (23 hours in Europe/Zurich)
```

## Custom periods move by their own length

A period with the unit `"custom"` (from [`period`](../period/), or a piece cut
by [`divide`](../divide/)) moves back by exactly its own length. The clipped
one-day week at the start of March 2026 moves back one day, not one week:

```ts
import { divide, month, previous } from "@aleksejdix/minuta";

const [firstPiece] = divide(
  month(Temporal.PlainDate.from("2026-03-01")),
  "week"
);
// → { start: 2026-03-01, end: 2026-03-02, unit: "custom" }

previous(firstPiece);
// → { start: 2026-02-28, end: 2026-03-01, unit: "custom" }
```

## Errors

`previous` throws a `RangeError` whose message starts with a code:

| Code                 | When                               |
| -------------------- | ---------------------------------- |
| `UNIT_NOT_SUPPORTED` | `period.unit` is not a known unit. |
