Cut a period down to the part that lies inside some bounds. Use it to keep a
selection within the allowed dates, or to find the overlap of two periods.

```ts
import { clamp } from "@aleksejdix/minuta";
```

```ts
clamp(period, bounds);
```

## Example

```ts
import { clamp, range } from "@aleksejdix/minuta";

const selection = range(
  Temporal.PlainDate.from("2026-01-05"),
  Temporal.PlainDate.from("2026-01-25")
);
const allowed = range(
  Temporal.PlainDate.from("2026-01-10"),
  Temporal.PlainDate.from("2026-01-20")
);

clamp(selection, allowed);
// → { start: 2026-01-10, end: 2026-01-20, unit: "custom" }
```

## Parameters

| Name     | What it is                   |
| -------- | ---------------------------- |
| `period` | The period to cut.           |
| `bounds` | The period it must fit into. |

## Returns

The part of `period` that is inside `bounds`: it starts at the later of the
two starts and ends at the earlier of the two ends. Its unit is always
`"custom"`.

`undefined` when the two share no time, also when they only touch.

Next to a time period, a date period becomes moments in that period's zone,
so you can clamp days to a range of moments.

## No overlap gives undefined

```ts
import { period } from "@aleksejdix/minuta";

const march = period(Temporal.PlainDate.from("2026-03-01"), "month");

clamp(period(Temporal.PlainDate.from("2026-03-15"), "day"), march);
// → { start: 2026-03-15, end: 2026-03-16, unit: "custom" }

clamp(period(Temporal.PlainDate.from("2026-04-15"), "day"), march);
// → undefined (April 15 is not in March)
```

## Touching at one moment

A period's `end` is excluded. When the end of one is exactly the start of
the other, they share no time, and the result is `undefined`:

```ts
clamp(
  range(
    Temporal.PlainDate.from("2026-01-01"),
    Temporal.PlainDate.from("2026-01-10")
  ),
  range(
    Temporal.PlainDate.from("2026-01-10"),
    Temporal.PlainDate.from("2026-01-20")
  )
);
// → undefined (they only touch)
```

## The unit is lost

The result is always `"custom"`, even when nothing was cut:

```ts
clamp(march, march);
// → { start: 2026-03-01, end: 2026-04-01, unit: "custom" }
```

If you need the unit back, use [`merge([result], "month")`](../merge/): it
gives the unit `"month"` back when the result is exactly one month.

## Order matters only for naming

`clamp(a, b)` and `clamp(b, a)` give the same start and end: both are the
overlap. The names just say which one you think of as the limit.
