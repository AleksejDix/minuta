description: Check whether a period lies completely on working days — no Saturday, no Sunday, or no day of the weekend you set.

import { plainDate } from "../../../../components/temporal";
import { divide, period, range } from "@aleksejdix/minuta";
import { isWeekdayWith } from "@aleksejdix/minuta/calendar";
import { createUnits } from "@aleksejdix/minuta/core";
import MonthGrid from "../../../../components/diagrams/MonthGrid.astro";
import Timeline from "../../../../components/diagrams/Timeline.astro";

export const march = period(plainDate("2026-03-01"), "month");
export const days = divide(march, "day");
export const week = period(plainDate("2026-03-18"), "week");
export const iso = (day) => day.start.toString();

Check whether a period lies completely on working days, that is, days that
are not part of the weekend. The weekend is Saturday and Sunday unless you
set other days in the units.

```ts
import { isWeekdayWith } from "@aleksejdix/minuta/calendar";
```

```ts
isWeekdayWith(units, period);
```

## Example

```ts
import { isWeekdayWith } from "@aleksejdix/minuta/calendar";
import { createUnits } from "@aleksejdix/minuta/core";
import { divide, period } from "@aleksejdix/minuta";

const units = createUnits();

isWeekdayWith(units, period(Temporal.PlainDate.from("2026-03-18"), "day")); // → true  (a Wednesday)
isWeekdayWith(units, period(Temporal.PlainDate.from("2026-03-21"), "day")); // → false (a Saturday)

// The working days of March 2026
divide(period(Temporal.PlainDate.from("2026-03-01"), "month"), "day").filter(
  (day) => isWeekdayWith(units, day)
).length;
// → 22
```

The dots mark those 22 days: every day of March 2026 for which
`isWeekdayWith(units, day)` returns `true`. The shaded weekend days have
none.

<MonthGrid
  month="2026-03"
  marks={days.filter((day) => isWeekdayWith(createUnits(), day)).map(iso)}
/>

## Parameters

| Name     | What it is                                                                     |
| -------- | ------------------------------------------------------------------------------ |
| `units`  | The units to compute with, e.g. `createUnits()`. Only their `weekend` is used. |
| `period` | The period to check: a day, an hour, a range of days, …                        |

## Returns

`true` when no day the period touches is a weekend day, otherwise `false`.

## Another weekend

Set the weekend when you create the units. Then Sunday is a working day:

```ts
const units = createUnits({ weekend: ["friday", "saturday"] });

isWeekdayWith(units, period(Temporal.PlainDate.from("2026-03-22"), "day")); // → true  (a Sunday)
isWeekdayWith(units, period(Temporal.PlainDate.from("2026-03-20"), "day")); // → false (a Friday)
```

The working days of March 2026 with both settings. With Friday and Saturday
off, Sundays become working days, and March has 23 of them:

<Timeline
  caption="Each bar is a day of March 2026 for which isWeekdayWith returns true; the gaps are the weekends."
  tracks={[
    { label: "march", periods: [march], tone: "muted" },
    {
      label: '["saturday", "sunday"]',
      periods: days.filter((day) => isWeekdayWith(createUnits(), day)),
      tone: "accent",
    },
    {
      label: '["friday", "saturday"]',
      periods: days.filter((day) =>
        isWeekdayWith(createUnits({ weekend: ["friday", "saturday"] }), day)
      ),
      tone: "accent",
    },
  ]}
/>

minuta knows nothing about public holidays. A holiday on a Tuesday is a
working day for `isWeekdayWith`.

## Periods longer than a day

Every day the period touches counts, even partly:

```ts
import { range } from "@aleksejdix/minuta";

const units = createUnits();

// Mon Mar 16 – Fri Mar 20 (the end, Sat Mar 21, is excluded)
isWeekdayWith(
  units,
  range(
    Temporal.PlainDate.from("2026-03-16"),
    Temporal.PlainDate.from("2026-03-21")
  )
);
// → true

isWeekdayWith(units, period(Temporal.PlainDate.from("2026-03-18"), "week")); // → false (has Sat and Sun)
isWeekdayWith(units, period(Temporal.PlainDate.from("2026-03-01"), "month")); // → false
```

<Timeline
  caption="The week of Mar 16 2026. Monday to Friday stays inside the working days (top row); the whole week also covers the weekend."
  tracks={[
    {
      label: "working days",
      periods: divide(week, "day").filter((day) =>
        isWeekdayWith(createUnits(), day)
      ),
      tone: "muted",
    },
    {
      label: "Mon – Fri: true",
      periods: [range(plainDate("2026-03-16"), plainDate("2026-03-21"))],
      tone: "accent",
    },
    { label: "the week: false", periods: [week] },
  ]}
/>

A period with both kinds of days is neither: both `isWeekdayWith` and
[`isWeekendWith`](../is-weekend-with/) return `false`.

A time period's days are read in its own zone, see
[`isWeekendWith`](../is-weekend-with/#time-zones).

## Errors

`isWeekdayWith` does not throw: it needs no unit specs, only the `weekend`
setting (Saturday and Sunday when the units have none). It does not check
the period: pass a valid one, e.g. from `period()`.
