Build the days of a month view for a calendar: always 6 weeks of 7 days,
starting on the first day of your week.

```ts
import { monthGridWith } from "@aleksejdix/minuta/calendar";
```

```ts
monthGridWith(units, value);
```

## Example

```ts
import { monthGridWith } from "@aleksejdix/minuta/calendar";
import { createUnits } from "@aleksejdix/minuta/core";

const grid = monthGridWith(
  createUnits(),
  Temporal.PlainDate.from("2026-03-15")
);

grid.periods.length; // → 42
grid.periods[0]; // → { start: 2026-02-23, end: 2026-02-24, unit: "day" }, a Monday
grid.periods[41]; // → { start: 2026-04-05, end: 2026-04-06, unit: "day" }
grid.monthStart; // → 2026-03-01
grid.weekStartsOn; // → 1 (Monday)
```

Laid out in rows of 7, March 2026 looks like this:

The grey numbers are the 11 days from February and April that fill the
first and the last rows. The shaded days are the weekend.

## Parameters

| Name    | What it is                                                                                                                      |
| ------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `units` | The units to compute with, e.g. `createUnits()`. They decide the week start and the time zone. Needs `month`, `week` and `day`. |
| `value` | Any date or moment inside the month you want. Mar 15 and Mar 31 give the same grid.                                             |

## Returns

An object with three fields:

- `periods` — 42 day periods (6 weeks of 7 days), in order, row by row. Each
  is a whole day with the unit `"day"`.
- `monthStart` — the first day of the month as a `PlainDate`, e.g. 2026-03-01.
- `weekStartsOn` — the first day of the week as a number: 0 = Sunday,
  1 = Monday … 6 = Saturday.

To get the rows, cut `periods` into pieces of 7:

```ts
const weeks = [];
for (let i = 0; i < 42; i += 7) weeks.push(grid.periods.slice(i, i + 7));
// → 6 arrays of 7 days
```

## Always 42 days

The grid has 42 days for every month, even when 5 rows would do. A month
view built from it never changes height when the user goes to the next
month, so the layout does not jump.

February 2021 has 28 days and starts on a Monday. It fills exactly 4 rows,
and the grid adds 2 more rows from March:

```ts
const feb = monthGridWith(createUnits(), Temporal.PlainDate.from("2021-02-10"));

feb.periods[0].start; // → 2021-02-01, a Monday (no days from January)
feb.periods[41].start; // → 2021-03-14 (the last 2 rows are all March)
```

<MonthGrid month="2021-02" />

Feb 1 is the very first cell, and the two grey rows at the bottom are the
days Mar 1 to Mar 14 that keep the grid at 42 days.

## Days outside the month

The first row usually starts in the previous month, and the last rows end in
the next one. These are often shown greyed out. In the March 2026 grid, 11 of
the 42 days are not in March: the grey numbers in the
[first picture](#example).

To find them, check each day against the month with `contains`:

```ts
import { contains, periodWith } from "@aleksejdix/minuta/core";

const units = createUnits();
const grid = monthGridWith(units, Temporal.PlainDate.from("2026-03-15"));
const month = periodWith(units, grid.monthStart, "month");

grid.periods.filter((day) => !contains(month, day)).length;
// → 11
```

The days are `PlainDate`s with no time zone, so comparing
`day.start.month` with `grid.monthStart.month` works just as well.

## Week start

The grid starts on the first day of the week of the `units`. It is Monday
unless you choose another day:

```ts
const sunday = monthGridWith(
  createUnits({ weekStartsOn: "sunday" }),
  Temporal.PlainDate.from("2026-03-15")
);

sunday.periods[0].start; // → 2026-03-01 (March starts on a Sunday)
sunday.periods[41].start; // → 2026-04-11, a Saturday
sunday.weekStartsOn; // → 0
```

<MonthGrid month="2026-03" weekStartsOn="sunday" />

Mar 1 now sits in the first cell, so no day of February is left in the
grid, and the last two rows run into April up to Sat Apr 11.

The weekend does not change the grid. Use
[`isWeekendWith`](../is-weekend-with/) to mark weekend days.

## Days are real days

Each period is one calendar day: `start` is the day, `end` the next day, both
`PlainDate`s. There is no time zone, so a clock change cannot move or cut a
cell. Oct 25 2026 is `{ start: 2026-10-25, end: 2026-10-26 }` like any other
day; divide it into hours, or use [`dayGridWith`](../day-grid-with/), to see
its 25 hours in Europe/Zurich.

## Errors

`monthGridWith` throws a `RangeError` starting with `UNIT_NOT_SUPPORTED`
when `units` has no `month`, `week` or `day`.
