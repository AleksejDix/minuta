Turn a Temporal value into the segments a field shows, in its format:
`2026-03-31` in a `de-CH` date field is `31.03.2026`. A date shows its day,
a time its hour and minute, a date and time both. Parts the field derives (a
weekday, a day period, an era) are named off the value's wall clock, so the
runtime's time zone never moves one.

```ts
import { fromTemporal } from "@aleksejdix/datefield";
```

```ts
fromTemporal(value, format, locale);
```

## Example

```ts
import {
  deriveFormat,
  fromTemporal,
  segmentsToString,
} from "@aleksejdix/datefield";

const date = deriveFormat("de-CH");
const time = deriveFormat("en-GB", { hour: "2-digit", minute: "2-digit" });

segmentsToString(fromTemporal(Temporal.PlainDate.from("2026-03-31"), date)); // → "31.03.2026"
segmentsToString(fromTemporal(Temporal.PlainTime.from("09:30"), time)); // → "09:30"
```

## Parameters

- `value`: a `Temporal.PlainDate`, `PlainTime` or `PlainDateTime`.
- `format`: the field's format, from `deriveFormat`.
- `locale`: the locale its derived parts are written in; `en-US` when unset.

## Returns

The segments: one per format token, with its start, end, type and value.
