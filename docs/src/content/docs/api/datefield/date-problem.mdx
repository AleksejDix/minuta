The codes [`checkDate`](../check-date/) and [`checkDay`](../check-day/) return,
as named constants. Use them instead of typing the strings yourself.

```ts
import { DateProblem } from "@aleksejdix/datefield";
```

## Example

```ts
import { DateProblem, checkDate } from "@aleksejdix/datefield";

const messages = {
  [DateProblem.BeforeMin]: "Pick a date from today on.",
  [DateProblem.AfterMax]: "Pick a date before the end of the year.",
  [DateProblem.Unavailable]: "We are closed on that day.",
};

const problem = checkDate(segments, rules);
const message = problem === undefined ? "" : messages[problem];
```

## What it is

A plain object. Each name maps to the code string.

| Name          | Code                                   | When                             |
| ------------- | -------------------------------------- | -------------------------------- |
| `BeforeMin`   | <code>{DateProblem.BeforeMin}</code>   | The date is before `min`.        |
| `AfterMax`    | <code>{DateProblem.AfterMax}</code>    | The date is after `max`.         |
| `Unavailable` | <code>{DateProblem.Unavailable}</code> | `isUnavailable` returned `true`. |

The type of the codes is `DateProblemCode`.
