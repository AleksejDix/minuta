Check whether the user has filled any slot of a masked field yet.

```ts
import { isEmpty } from "@aleksejdix/input-state";
```

```ts
isEmpty(state);
```

## Example

```ts
import {
  createInputState,
  isEmpty,
  parseMask,
  typeChar,
} from "@aleksejdix/input-state";

const mask = parseMask("99.99.9999");
const field = createInputState({ mask });

isEmpty(field); // → true
isEmpty(typeChar(field, "3")); // → false
```

## Parameters

| Name    | What it is            |
| ------- | --------------------- |
| `state` | The field to look at. |

## Returns

`true` when every slot holds the placeholder, `false` otherwise. A free-text
field has no slots; it is empty when its text is `""`.

:::caution
A slot counts as empty when it holds the placeholder character. If your
placeholder is a character the slot can also take, such as `0` in a digit
mask, a typed `0` counts as empty.
:::
