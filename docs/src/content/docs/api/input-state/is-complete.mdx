title: isComplete
description: Whether every slot of a masked input field is filled.
---

import {
  createInputState,
  isComplete,
  parseMask,
} from "@aleksejdix/input-state";
import FieldDiagram from "../../../../components/diagrams/FieldDiagram.astro";

export const mask = parseMask("99.99.9999");
export const done = createInputState({ mask, value: "31032026" });
export const half = createInputState({ mask, value: "3103" });
export const impossible = createInputState({ mask, value: "31022026" });

Check whether the user has filled every slot of a masked field.

```ts
import { isComplete } from "@aleksejdix/input-state";
```

```ts
isComplete(state);
```

## Example

```ts
import {
  createInputState,
  isComplete,
  parseMask,
} from "@aleksejdix/input-state";

const mask = parseMask("99.99.9999");

isComplete(createInputState({ mask, value: "31032026" })); // → true
isComplete(createInputState({ mask, value: "3103" })); // → false
```

<FieldDiagram
  {...half.buffer.selection}
  text={half.buffer.text}
  mode={half.mode}
  caption={`value "3103": four slots still hold "_", so isComplete → ${String(isComplete(half))}.`}
/>

<FieldDiagram
  {...done.buffer.selection}
  text={done.buffer.text}
  mode={done.mode}
  caption={`value "31032026": no slot holds "_" any more, so isComplete → ${String(isComplete(done))}.`}
/>

## Parameters

| Name    | What it is            |
| ------- | --------------------- |
| `state` | The field to look at. |

## Returns

`true` when no slot holds the placeholder, `false` otherwise. A free-text
field has no slots, so it is always complete.

## Complete is not the same as valid

`isComplete` only counts filled slots. `"31.02.2026"` is complete, even
though February has no 31st. Check the value itself, for example with
[`toDate`](../../datefield/to-date/) in datefield.

<FieldDiagram
  {...impossible.buffer.selection}
  text={impossible.buffer.text}
  mode={impossible.mode}
  caption={`"31.02.2026": every slot is filled, so isComplete → ${String(isComplete(impossible))}, though the date does not exist.`}
/>

:::caution
A slot counts as empty when it holds the placeholder character. If your
placeholder is a character the slot can also take, such as `0` in a digit
mask, a typed `0` counts as empty.
:::
