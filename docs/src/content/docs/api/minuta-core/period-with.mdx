Get the whole unit of time that a date or moment falls in (its day, week,
month, hour), computed with the units you pass.

```ts
import { periodWith } from "@aleksejdix/minuta/core";
```

```ts
periodWith(units, value, unit);
```

## Example

```ts
import { createUnits, periodWith } from "@aleksejdix/minuta/core";

const units = createUnits({ weekStartsOn: "sunday" });

periodWith(units, Temporal.PlainDate.from("2026-03-18"), "week");
// → { start: 2026-03-15, end: 2026-03-22, unit: "week" }
```

Here `monday` is `createUnits()` and `sunday` is
`createUnits({ weekStartsOn: "sunday" })`. A month has no week start, so both
give March.

## Parameters

| Name    | What it is                                                                                                                            |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `units` | The units to compute with, e.g. [`createUnits()`](../create-units/).                                                                  |
| `value` | Any value inside the period you want: a `PlainDate`, `PlainDateTime`, `ZonedDateTime` or `Instant`.                                   |
| `unit`  | The size of the period: `"year"`, `"quarter"`, `"month"`, `"week"`, `"day"`, `"hour"`, `"minute"`, `"second"`, or a unit of your own. |

## Returns

A period: `{ start, end, unit }`, `start` included and `end` excluded. For
`"day"` and larger, `start` and `end` are `PlainDate`s; for `"hour"`,
`"minute"` and `"second"`, `ZonedDateTime`s in the value's zone, or in the
units' `timeZone` for a value without one. It works exactly like
[`period`](../../minuta/period/), which is `periodWith` with `createUnits()`
bound. Read that page for the details on every unit, time zones and daylight
saving.

## The units decide the rules

The same date gives different periods with different units:

```ts
import { createUnits, periodWith } from "@aleksejdix/minuta/core";

periodWith(createUnits(), Temporal.PlainDate.from("2026-03-18"), "week");
// → { start: 2026-03-16, end: 2026-03-23, unit: "week" } (weeks start on Monday by default)

const tokyo = createUnits({ timeZone: "Asia/Tokyo" });
periodWith(tokyo, Temporal.Instant.from("2026-03-20T20:00:00Z"), "day");
// → { start: 2026-03-21, end: 2026-03-22, unit: "day" }: Mar 21 in Tokyo, still Mar 20 in Zurich
```

## Only the units you pass

`units` can hold just the units you use. A unit that is not there throws:

```ts
const { day, month } = createUnits();

periodWith({ day, month }, Temporal.PlainDate.from("2026-03-18"), "month"); // works
periodWith({ day, month }, Temporal.PlainDate.from("2026-03-18"), "week");
// RangeError: UNIT_NOT_SUPPORTED: no "week" spec in the units passed (available: day, month). …
```

## Errors

`periodWith` throws a `RangeError` starting with `UNIT_NOT_SUPPORTED` when
`units` has no spec for `unit`, or `unit` is `"custom"`.
