Count how many whole units fit into a period (the hours in a day, the days in
a month), computed with the units you pass.

```ts
import { durationWith } from "@aleksejdix/minuta/core";
```

```ts
durationWith(units, period, unit);
```

## Example

```ts
import { createUnits, durationWith, periodWith } from "@aleksejdix/minuta/core";

const units = createUnits();

durationWith(
  units,
  periodWith(units, Temporal.PlainDate.from("2026-02-01"), "month"),
  "day"
);
// → 28

durationWith(
  units,
  periodWith(units, Temporal.PlainDate.from("2026-03-29"), "day"),
  "hour"
);
// → 23 in Europe/Zurich, the clocks go forward that night
```

## Parameters

| Name     | What it is                                                           |
| -------- | -------------------------------------------------------------------- |
| `units`  | The units to compute with, e.g. [`createUnits()`](../create-units/). |
| `period` | The period to measure.                                               |
| `unit`   | What to count: `"day"`, `"hour"`, `"week"`, `"month"`, …             |

## Returns

A whole number: how many complete `unit`s fit from the start of `period` to
its end. Units that only partly fit are not counted.

It works exactly like [`duration`](../../minuta/duration/), which is
`durationWith` with `createUnits()` bound. Read that page for partial units
and month ends.

## The time zone comes from the units

Whether a day has 23, 24 or 25 hours depends on the time zone. A date period
counted in hours becomes moments in the units' `timeZone`, wherever the code
runs:

```ts
import { createUnits, durationWith, periodWith } from "@aleksejdix/minuta/core";

const newYork = createUnits({ timeZone: "America/New_York" });
const day = periodWith(newYork, Temporal.PlainDate.from("2026-03-08"), "day");

durationWith(newYork, day, "hour");
// → 23, the clocks go forward in New York on Mar 8 2026
```

## Errors

`durationWith` throws a `RangeError` whose message starts with a code:

| Code                 | When                            |
| -------------------- | ------------------------------- |
| `UNIT_NOT_SUPPORTED` | `units` has no spec for `unit`. |
