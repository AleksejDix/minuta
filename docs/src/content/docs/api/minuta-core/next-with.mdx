export const sunday = createUnits({ weekStartsOn: "sunday" });
export const week = periodWith(sunday, plainDate("2026-03-18"), "week");
export const mondayWeek = periodWith(
  createUnits(),
  plainDate("2026-03-18"),

Get the period right after a period (the next day, week or month), computed
with the units you pass.

```ts
import { nextWith } from "@aleksejdix/minuta/core";
```

```ts
nextWith(units, period);
```

## Example

```ts
import { createUnits, nextWith, periodWith } from "@aleksejdix/minuta/core";

const units = createUnits({ weekStartsOn: "sunday" });
const week = periodWith(units, Temporal.PlainDate.from("2026-03-18"), "week");
// → { start: 2026-03-15, end: 2026-03-22, unit: "week" }

nextWith(units, week);
// → { start: 2026-03-22, end: 2026-03-29, unit: "week" }
```

## Parameters

| Name     | What it is                                                           |
| -------- | -------------------------------------------------------------------- |
| `units`  | The units to compute with, e.g. [`createUnits()`](../create-units/). |
| `period` | The current period.                                                  |

## Returns

A new, whole period of the same unit that starts where `period` ends.
`nextWith(units, p)` is the same as [`shiftWith(units, p, 1)`](../shift-with/).

It works exactly like [`next`](../../minuta/next/), which is `nextWith` with
`createUnits()` bound. Read that page for daylight saving and for custom
periods, which move by their own length.

## Use the same units as the period

Pass the units the period was made with. `nextWith` steps from the period's
start and then rounds to a whole unit with _these_ units. A Monday week moved
with Sunday units comes out as a Sunday week:

```ts
import { createUnits, nextWith, periodWith } from "@aleksejdix/minuta/core";

const mondayWeek = periodWith(
  createUnits(),
  Temporal.PlainDate.from("2026-03-18"),
  "week"
);
// → { start: 2026-03-16, end: 2026-03-23, unit: "week" }

nextWith(createUnits({ weekStartsOn: "sunday" }), mondayWeek);
// → { start: 2026-03-22, end: 2026-03-29, unit: "week" }
```

<Timeline
  caption="A Monday week moved with Sunday units lands on the Sunday grid: it starts on Sun Mar 22, the last day of mondayWeek, instead of on Mon Mar 23."
  tracks={[
    { label: "mondayWeek", periods: [mondayWeek], tone: "ink" },

[`withUnits`](../with-units/) makes this hard to get wrong: everything on the
bound object uses one set of units.

## Errors

`nextWith` throws a `RangeError` starting with `UNIT_NOT_SUPPORTED` when
`units` has no spec for `period.unit`.
