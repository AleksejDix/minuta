Look up the rules for one unit in a set of units, for example to find the
start of a week or to add a month with exactly the rules minuta uses.

```ts
import { specFor } from "@aleksejdix/minuta/core";
```

```ts
specFor(units, unit);
```

## Example

```ts
import { createUnits, specFor } from "@aleksejdix/minuta/core";

const week = specFor(createUnits(), "week");

week.startOf(Temporal.PlainDate.from("2026-03-18"));
// → 2026-03-16, a Monday
```

## Parameters

| Name    | What it is                                                        |
| ------- | ----------------------------------------------------------------- |
| `units` | A set of units, usually from [`createUnits()`](../create-units/). |
| `unit`  | The unit to look up: `"day"`, `"week"`, `"month"`, …              |

## Returns

The _spec_ of that unit: its `kind` and three functions. Every unit-aware
operation in minuta is built from these three.

| Member               | What it is                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| `kind`               | `"date"` for `"day"` and larger (works on `PlainDate`), `"time"` for `"hour"` and smaller (`ZonedDateTime`). |
| `startOf(value)`     | The start of the unit that contains `value`.                                                                 |
| `add(value, amount)` | `value` moved by `amount` units; negative moves back.                                                        |
| `diff(from, to)`     | How many whole units fit from `from` to `to`, rounded toward zero.                                           |

There is no `endOf`: a unit ends where the next one starts, at
`add(startOf(value), 1)`.

```ts
const month = specFor(createUnits(), "month");

month.startOf(Temporal.PlainDate.from("2026-02-10")); // → 2026-02-01
month.add(Temporal.PlainDate.from("2026-01-31"), 1); // → 2026-02-28
month.diff(
  Temporal.PlainDate.from("2026-01-31"),
  Temporal.PlainDate.from("2026-02-28")
); // → 1
```

Adding a month to Jan 31 gives Feb 28: the day is cut to fit the shorter
month.

## When to use it

Most code never needs `specFor`: use [`periodWith`](../period-with/) or
[`withUnits`](../with-units/) instead. It is useful when you write a function
or a unit of your own, and want the same lookup, and the same error, as the
built-in operations.

## Errors

`specFor` throws a `RangeError` whose message starts with a code:

| Code                 | When                            |
| -------------------- | ------------------------------- |
| `UNIT_NOT_SUPPORTED` | `units` has no spec for `unit`. |

The message lists the units that _are_ there:

```ts
const { day, month } = createUnits();

specFor({ day, month }, "hour");
// RangeError: UNIT_NOT_SUPPORTED: no "hour" spec in the units passed (available: day, month). …
```
