---
title: selectionEnd
description: The right edge of a buffer's selection, whichever way it was made.
---

Get the right edge of the selection: the larger of `anchor` and `head`.

```ts
import { selectionEnd } from "text-buffer";
```

```ts
selectionEnd(buffer);
```

## Example

```ts
import { createTextBuffer, selectionEnd } from "text-buffer";

selectionEnd(createTextBuffer("hello", { anchor: 1, head: 4 })); // → 4
selectionEnd(createTextBuffer("hello", { anchor: 4, head: 1 })); // → 4
```

## Parameters

| Name     | What it is             |
| -------- | ---------------------- |
| `buffer` | The buffer to look at. |

## Returns

A position in the text. For a forward selection it is `head`, for a backward
selection it is `anchor`, and for a plain cursor it is the cursor position.
