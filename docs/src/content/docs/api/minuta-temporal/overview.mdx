minuta computes with [Temporal](https://tc39.es/proposal-temporal/docs/).
Chrome and Edge 144+, Firefox 139+ and Node 26+ have it built in; Safari and
Node 24 do not yet. `@aleksejdix/minuta/temporal` closes that gap: await
`temporalReady()` once, and it loads `@js-temporal/polyfill` only where
Temporal is missing.

```ts
import { temporalReady } from "@aleksejdix/minuta/temporal";
```

It is a separate entry point, so the polyfill is never in a bundle that does
not import it.

## Functions

| Function                              | What it does                                 |
| ------------------------------------- | -------------------------------------------- |
| [`temporalReady`](../temporal-ready/) | Load the polyfill where Temporal is missing. |

The units minuta computes with come from
[`createUnits`](../../minuta-core/create-units/) in `@aleksejdix/minuta/core`.
