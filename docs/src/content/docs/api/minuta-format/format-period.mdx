---
title: formatPeriod
description: Turn a period into a label in any language — "March 2026", "15. März 2026", "Mar 9 – 15, 2026" — picked by the period's unit.
---

import { plainDate, zonedDateTime } from "../../../../components/temporal";
import { divide, period } from "@aleksejdix/minuta";
import { formatPeriod, formatRange } from "@aleksejdix/minuta/format";
import Timeline from "../../../../components/diagrams/Timeline.astro";

export const date = zonedDateTime("2026-03-15T14:05:09[Europe/Zurich]");
export const labelled = (units) =>
  units.map((unit) => ({
    label: `${unit}: ${formatPeriod(period(date, unit), "en-US")}`,
    periods: [period(date, unit)],
    tone: "accent",
  }));
export const q2 = period(plainDate("2026-05-01"), "quarter");

Turn a period into a label for people to read, in any language: "March
2026", "15. März 2026", "Mar 9 – 15, 2026". The format is picked by the
period's unit.

```ts
import { formatPeriod } from "@aleksejdix/minuta/format";
```

```ts
formatPeriod(period, locale, options?)
```

## Example

```ts
import { formatPeriod } from "@aleksejdix/minuta/format";
import { period } from "@aleksejdix/minuta";

const date = Temporal.ZonedDateTime.from("2026-03-15T14:05:09[Europe/Zurich]");

formatPeriod(period(date, "month"), "en-US"); // → "March 2026"
formatPeriod(period(date, "month"), "de-CH"); // → "März 2026"
formatPeriod(period(date, "day"), "en-US"); // → "March 15, 2026"
formatPeriod(period(date, "week"), "en-US"); // → "Mar 9 – 15, 2026"
```

## Parameters

| Name      | What it is                                                                                            |
| --------- | ----------------------------------------------------------------------------------------------------- |
| `period`  | The period to label.                                                                                  |
| `locale`  | The language and region, as a BCP 47 tag: `"en-US"`, `"de-CH"`, `"ja-JP"`, …                          |
| `options` | Optional. `Intl.DateTimeFormat` options that replace or add to the defaults, see [Options](#options). |

## Returns

The label, a string. It is made by the browser's or Node's built-in
`Intl.DateTimeFormat`, so minuta ships no language data.

## One format per unit

The unit of the period decides what the label shows. For Sun Mar 15 2026,
14:05:09:

| Unit      | `"en-US"`          | `"de-CH"`          | `"ja-JP"`              |
| --------- | ------------------ | ------------------ | ---------------------- |
| `year`    | 2026               | 2026               | 2026年                 |
| `quarter` | Jan 2026           | Jan. 2026          | 2026年1月              |
| `month`   | March 2026         | März 2026          | 2026年3月              |
| `week`    | Mar 9 – 15, 2026   | 9.–15. März 2026   | 2026/03/09～2026/03/15 |
| `day`     | March 15, 2026     | 15. März 2026      | 2026年3月15日          |
| `hour`    | Mar 15, 2:00 PM    | 15. März, 14:00    | 3月15日 14:00          |
| `minute`  | Mar 15, 2:05 PM    | 15. März, 14:05    | 3月15日 14:05          |
| `second`  | Mar 15, 2:05:09 PM | 15. März, 14:05:09 | 3月15日 14:05:09       |

larger units first:

Weeks and `"custom"` periods are shown as a range from start to end, the
same as [`formatRange`](../format-range/). All other units show their start.
A period of dates shows its last day, the day before its excluded `end`:

```ts
import { range } from "@aleksejdix/minuta";

formatPeriod(
  range(
    Temporal.PlainDate.from("2026-03-30"),
    Temporal.PlainDate.from("2026-04-06")
  ),
  "en-US"
);
// → "Mar 30 – Apr 5, 2026"
```

## Quarters show their first month

A quarter is labelled with the month it starts in, which may not be what you
want: Q2 2026 becomes "Apr 2026". Use `formatRange` to show all three
months:

```ts
import { formatRange } from "@aleksejdix/minuta/format";

const q2 = period(Temporal.PlainDate.from("2026-05-01"), "quarter");

formatPeriod(q2, "en-US"); // → "Apr 2026"
formatRange(q2, "en-US"); // → "Apr – Jun 2026"
```

## Options

`options` are the options of
[`Intl.DateTimeFormat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/DateTimeFormat#options).
Options that pick fields (`year`, `month`, `day`, `weekday`, `hour`,
`dateStyle`, `timeStyle` …) replace the defaults of the period's unit: list
every field you want. Other options, such as `hourCycle` or `timeZone`, are
added to the defaults.

```ts
formatPeriod(period(date, "month"), "en-US", { month: "short" });
// → "Mar"

formatPeriod(period(date, "month"), "en-US", {
  month: "short",
  year: "numeric",
});
// → "Mar 2026"

formatPeriod(period(date, "day"), "en-US", { weekday: "long" });
// → "Sunday"

formatPeriod(period(date, "day"), "en-US", { dateStyle: "full" });
// → "Sunday, March 15, 2026"
```

## Time zones

A period of moments is written in its own time zone, the zone of its
`ZonedDateTime`s, wherever the code runs. A period of dates has no zone: it
shows the same day everywhere.

```ts
const tokyo = Temporal.ZonedDateTime.from("2026-03-21T05:00[Asia/Tokyo]");

formatPeriod(period(tokyo, "day"), "en-US"); // → "March 21, 2026"
formatPeriod(period(tokyo, "hour"), "en-US"); // → "Mar 21, 5:00 AM"
```

To show moments in another zone, pass `timeZone`. It has no effect on a
period of dates.

```ts
formatPeriod(period(tokyo, "hour"), "en-US", { timeZone: "Europe/Zurich" });
// → "Mar 20, 9:00 PM"
```

## Other calendars

A period made in another calendar is labelled in that calendar: a Hebrew
month reads "Adar I 5784", a Hijri month "Ramadan 1447 AH". See
[calendars](../../minuta-core/create-units/#calendars). The `calendar` option
picks another one for the label only.

```ts
const ramadan = withUnits(createUnits({ calendar: "islamic-umalqura" })).period(
  Temporal.PlainDate.from("2026-03-18"),
  "month"
);
formatPeriod(ramadan, "en-US"); // → "Ramadan 1447 AH"
formatPeriod(ramadan, "en-US", { calendar: "gregory", dateStyle: "long" }); // → "February 18, 2026"
```

For an ISO period, the locale can ask for another calendar system with
`-u-ca-`. Only the label changes; the period is still the same Gregorian
month.

```ts
formatPeriod(period(date, "month"), "en-US-u-ca-buddhist"); // → "March 2569 BE"
```

In a locale whose calendar has other month borders, the label is the
month of the period's **start**: for March 2026, `"fa-IR"` gives
"۱۴۰۴ اسفند", the Persian month in which March 1 falls.

## Custom units

A period with a unit minuta has no format for (a unit you added yourself) is
labelled like a `"custom"` date, but only with its start:
"Mar 1, 2026". Use `formatRange` to show start and end.

## Errors

`formatPeriod` throws the errors of `Intl.DateTimeFormat`:

| Error        | When                                                            |
| ------------ | --------------------------------------------------------------- |
| `RangeError` | `locale` is not a valid tag, or an option has an invalid value. |
| `TypeError`  | `options` conflict, e.g. `dateStyle` together with `month`.     |
