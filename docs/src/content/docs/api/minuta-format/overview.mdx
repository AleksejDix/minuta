export const march = period(plainDate("2026-03-15"), "month");
export const marchToApril = range(

  plainDate("2026-04-06")
);

`@aleksejdix/minuta/format` turns periods into text for people: "March 2026", "Mar 9 –
15, 2026", "30. März – 5. Apr. 2026". It uses the `Intl.DateTimeFormat`
built into browsers and Node, so it ships no language data and works in
every locale they know.

```ts
import { formatPeriod, formatRange } from "@aleksejdix/minuta/format";
```

## Functions

| Function                            | What it does                                                            |
| ----------------------------------- | ----------------------------------------------------------------------- |
| [`formatPeriod`](../format-period/) | A label that fits the unit: a month as "March 2026", a week as a range. |
| [`formatRange`](../format-range/)   | Always "start – end", without repeating shared parts.                   |

## Example

```ts
import { formatPeriod, formatRange } from "@aleksejdix/minuta/format";
import { period, range } from "@aleksejdix/minuta";

const day = (iso) => Temporal.PlainDate.from(iso);

formatPeriod(period(day("2026-03-15"), "month"), "de-CH");
// → "März 2026"

formatRange(range(day("2026-03-30"), day("2026-04-06")), "de-CH");
// → "30. März – 5. Apr. 2026", the end (Apr 6) is excluded
```

## Key ideas

- **The unit picks the format.** A `"month"` period shows month and year, a
  `"day"` period the full date, an `"hour"` period the date and time. See
  the [table](../format-period/#one-format-per-unit).
- **Options override.** Options that pick fields, e.g.
  `{ month: "short", year: "numeric" }`, replace the unit's defaults. Others,
  such as `hourCycle`, are added to them.
- **Time zone.** Moments are written in their own zone unless you pass
  `{ timeZone }`. Dates have no zone: a day shows the same everywhere.
- **The end is excluded.** A period of dates is shown up to its last day,
  the day before `end`.
- **No units needed.** The format functions only read `start`, `end` and
  `unit` of the period.
