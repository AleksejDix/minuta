`minuta-vue` connects [minuta](../../minuta/divide/) to Vue. It keeps the
period you are looking at (for example "March 2026") in reactive state, and it
ships calendar components you can put together like building blocks. The API
mirrors [minuta-react](../../minuta-react/overview/).

## Install

```sh
npm install minuta minuta-vue
```

`vue` is a peer dependency. The calendar components use `useId` and
`useTemplateRef`, which need Vue 3.5 or newer.

The calendar components come with styles in one stylesheet. Import it once,
for example in `main.js`:

```js
import "minuta-vue/style.css";
```

Leave it out to style the components from scratch.

## How it is built

There are three layers, each one small:

1. **The minuta core** does the date math. It is plain functions with no
   state: `period`, `next`, `divide`, … See [divide](../../minuta/divide/).
2. **A composable and a root.** [`useMinuta`](../use-minuta/) binds every
   core function to your units and keeps the _browsed period_ in a ref.
   [`MinutaRoot`](../minuta-root/) calls it once and provides the result to
   every component below it. Children read it with
   [`useMinutaContext`](../use-minuta-context/) or
   [`usePeriod`](../use-period/).
3. **Calendar parts.** [`CalendarRoot`](../calendar-root/) is a `MinutaRoot`
   that browses months and also remembers the selected and the focused day.
   [`CalendarHeader`](../calendar-header/), [`CalendarGrid`](../calendar-grid/),
   [`CalendarWeekdays`](../calendar-weekdays/) and
   [`CalendarDay`](../calendar-day/) read that state. You choose which parts
   to render and where.

One click on "Next →" passes through all three layers:

## Example

A month calendar. Clicking a day (or pressing Enter on it) selects it, and the
text below the grid shows the chosen date.

```vue
<script setup>
import { shallowRef } from "vue";
import {
  CalendarGrid,
  CalendarHeader,
  CalendarRoot,
} from "minuta-vue/components";
import "minuta-vue/style.css";

const picked = shallowRef();
</script>

<template>
  <CalendarRoot @select="(day) => (picked = day.start)">
    <CalendarHeader />
    <CalendarGrid />
  </CalendarRoot>
  <p>{{ picked ? picked.toDateString() : "Pick a day" }}</p>
</template>
```

This renders the current month with "← Previous" and "Next →" buttons, a row
of weekday names starting on Monday, and 6 weeks of days. `day` is a
[period](../../minuta/period/): `day.start` is midnight at the start of the
chosen day.

## Exports

From `minuta-vue`:

| Export                                       | What it is                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------- |
| [`useMinuta`](../use-minuta/)                | Composable: every minuta function bound to your units, plus the browsed period. |
| [`MinutaRoot`](../minuta-root/)              | Component: runs `useMinuta` once and provides it to its children.               |
| [`useMinutaContext`](../use-minuta-context/) | Composable: reads the state of the nearest `MinutaRoot`.                        |
| [`usePeriod`](../use-period/)                | Composable: the year, week, day, … that contains the browsed period's start.    |
| [`CalendarExample`](../calendar-example/)    | Component: a ready-made month calendar with a week start toggle.                |

From `minuta-vue/components`:

| Export                                      | What it is                                                         |
| ------------------------------------------- | ------------------------------------------------------------------ |
| [`CalendarRoot`](../calendar-root/)         | Holds the calendar state: browsed month, selected and focused day. |
| [`CalendarHeader`](../calendar-header/)     | The month name between "previous" and "next" buttons.              |
| [`CalendarGrid`](../calendar-grid/)         | The month as a table of 6 weeks, with keyboard navigation.         |
| [`CalendarWeekdays`](../calendar-weekdays/) | The row of weekday names above the grid.                           |
| [`CalendarDay`](../calendar-day/)           | One day button.                                                    |
| [`CalendarExample`](../calendar-example/)   | The same ready-made calendar as above.                             |

`minuta-vue/types` exports the TypeScript types only, and
`minuta-vue/style.css` is the stylesheet of the components.
