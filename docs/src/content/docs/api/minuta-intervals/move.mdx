Move a period so it starts at a new date or moment, and keep its length.
Use it to drag an appointment to another time.

```ts
import { move } from "@aleksejdix/minuta/intervals";
```

```ts
move(period, target);
```

## Example

```ts
import { move } from "@aleksejdix/minuta/intervals";
import { range } from "@aleksejdix/minuta";

const appointment = range(
  Temporal.ZonedDateTime.from("2026-03-29T09:00[Europe/Zurich]"),
  Temporal.ZonedDateTime.from("2026-03-29T10:00[Europe/Zurich]")
);

move(
  appointment,
  Temporal.ZonedDateTime.from("2026-04-02T14:00[Europe/Zurich]")
);
// → { start: 2026-04-02T14:00, end: 2026-04-02T15:00, unit: "custom" }
```

## Parameters

| Name     | What it is                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------- |
| `period` | The period to move.                                                                                  |
| `target` | Where the moved period starts: a `PlainDate` for a date period, a `ZonedDateTime` for a time period. |

## Returns

A new period that starts at `target` and is as long as `period`: as many
days for a date period, as much exact time for a time period. Its unit is
always `"custom"`. The original period is not changed.

## The length is kept, not the calendar meaning

`move` keeps the length, not the unit. That makes a difference for months,
and for moments when the clocks change.

February 2026 has 28 days. Moved to March 1, it still lasts 28 days:

```ts
import { period } from "@aleksejdix/minuta";

move(
  period(Temporal.PlainDate.from("2026-02-01"), "month"),
  Temporal.PlainDate.from("2026-03-01")
);
// → { start: 2026-03-01, end: 2026-03-29, unit: "custom" } (not all of March)
```

A time period keeps its exact time. The 24 hours from Mar 28 00:00, moved
to Mar 29, when the clocks in Europe/Zurich go forward, still last 24 hours
and end one hour into the next day:

```ts
const saturday = range(
  Temporal.ZonedDateTime.from("2026-03-28T00:00[Europe/Zurich]"),
  Temporal.ZonedDateTime.from("2026-03-29T00:00[Europe/Zurich]")
);

move(saturday, Temporal.ZonedDateTime.from("2026-03-29T00:00[Europe/Zurich]"));
// → { start: 2026-03-29T00:00, end: 2026-03-30T01:00, unit: "custom" }
```

A date period has no clock: `move(period(mar28, "day"), mar29)` is simply
Mar 29, one day.

To move by whole calendar units instead, use
[`shift`](../../minuta/shift/), e.g. `shift(february, 1)` gives all of March.

## Errors

`move` throws a `TypeError` when `target` is not of the period's kind, such
as a `ZonedDateTime` for a date period.
