Get the free time between two dates or periods, such as the break between
two meetings or the days between two bookings.

```ts
import { gap } from "@aleksejdix/minuta/intervals";
```

```ts
gap(from, to);
```

## Example

```ts
import { gap } from "@aleksejdix/minuta/intervals";
import { period } from "@aleksejdix/minuta";

gap(
  period(Temporal.PlainDate.from("2026-03-02"), "day"),
  period(Temporal.PlainDate.from("2026-03-05"), "day")
);
// → { start: 2026-03-03, end: 2026-03-05, unit: "custom" }
```

## Parameters

| Name   | What it is                        |
| ------ | --------------------------------- |
| `from` | One date, moment or period.       |
| `to`   | The other date, moment or period. |

Dates are `Temporal.PlainDate`, moments `Temporal.ZonedDateTime`. You can mix
them: a period and a moment work too. Next to moments, a date's day becomes
moments in their zone.

## Returns

The period between the two: it starts where the earlier one ends and ends
where the later one starts. Its unit is always `"custom"`.

`undefined` when there is no time between them: they touch or overlap.

## Order does not matter

`gap` finds out which one comes first:

```ts
gap(
  period(Temporal.PlainDate.from("2026-03-05"), "day"),
  period(Temporal.PlainDate.from("2026-03-02"), "day")
);
// → { start: 2026-03-03, end: 2026-03-05, unit: "custom" }, the same as above
```

## Touching or overlapping periods have no gap

Mar 2 ends where Mar 3 starts. Nothing lies between them:

```ts
gap(
  period(Temporal.PlainDate.from("2026-03-02"), "day"),
  period(Temporal.PlainDate.from("2026-03-03"), "day")
);
// → undefined (they touch)

gap(
  period(Temporal.PlainDate.from("2026-03-02"), "day"),
  period(Temporal.PlainDate.from("2026-03-01"), "month")
);
// → undefined (March contains Mar 2)
```

## Dates and moments

A date counts as its whole day, a moment as a single instant:

```ts
gap(
  Temporal.PlainDate.from("2026-03-02"),
  Temporal.PlainDate.from("2026-03-05")
);
// → { start: 2026-03-03, end: 2026-03-05, unit: "custom" }

gap(
  Temporal.ZonedDateTime.from("2026-03-02T09:00[Europe/Zurich]"),
  Temporal.ZonedDateTime.from("2026-03-02T10:00[Europe/Zurich]")
);
// → 09:00 – 10:00

gap(
  period(
    Temporal.ZonedDateTime.from("2026-03-02T09:00[Europe/Zurich]"),
    "hour"
  ),
  Temporal.ZonedDateTime.from("2026-03-02T12:00[Europe/Zurich]")
);
// → 10:00 – 12:00 (the hour from 9:00 ends at 10:00)
```

To measure a gap, pass it to `duration`, e.g.
`duration(gap(a, b), "minute")`.
