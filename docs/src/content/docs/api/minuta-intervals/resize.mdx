Move the start or the end of a period while the other edge stays where it
is. Use it to make a meeting longer or to start a booking earlier.

```ts
import { resize } from "@aleksejdix/minuta/intervals";
```

```ts
resize(period, edge, value);
```

## Example

```ts
import { resize } from "@aleksejdix/minuta/intervals";
import { range } from "@aleksejdix/minuta";

const meeting = range(
  Temporal.ZonedDateTime.from("2026-03-29T09:00[Europe/Zurich]"),
  Temporal.ZonedDateTime.from("2026-03-29T10:00[Europe/Zurich]")
);

resize(
  meeting,
  "end",
  Temporal.ZonedDateTime.from("2026-03-29T11:30[Europe/Zurich]")
);
// → { start: 09:00, end: 11:30, unit: "custom" }

resize(
  meeting,
  "start",
  Temporal.ZonedDateTime.from("2026-03-29T08:00[Europe/Zurich]")
);
// → { start: 08:00, end: 10:00, unit: "custom" }
```

## Parameters

| Name     | What it is                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------- |
| `period` | The period to change.                                                                              |
| `edge`   | Which edge to move: `"start"` or `"end"`.                                                          |
| `value`  | The new value for that edge: a `PlainDate` for a date period, a `ZonedDateTime` for a time period. |

## Returns

A new period with the moved edge. Its unit is always `"custom"`. The
original period is not changed.

`undefined` when the new edge would cross the other one, that is, when the
start would come after the end.

## Edges that cross

```ts
resize(
  meeting,
  "start",
  Temporal.ZonedDateTime.from("2026-03-29T11:00[Europe/Zurich]")
);
// → undefined (11:00 is after the end, 10:00)

resize(
  meeting,
  "end",
  Temporal.ZonedDateTime.from("2026-03-29T08:59[Europe/Zurich]")
);
// → undefined (8:59 is before the start, 9:00)
```

Moving an edge onto the other one is allowed. The result is an empty period:

```ts
resize(
  meeting,
  "end",
  Temporal.ZonedDateTime.from("2026-03-29T09:00[Europe/Zurich]")
);
// → { start: 09:00, end: 09:00, unit: "custom" }
```

## The end is excluded

A period runs up to, not including, its `end`. A day ends where the next day
starts. To make a date period end after Mar 3, pass Mar 4:

```ts
import { period } from "@aleksejdix/minuta";

const day = period(Temporal.PlainDate.from("2026-03-01"), "day");

resize(day, "end", Temporal.PlainDate.from("2026-03-04"));
// → { start: 2026-03-01, end: 2026-03-04, unit: "custom" } (Mar 1, 2 and 3)
```

## Errors

`resize` throws a `TypeError` when `value` is not of the period's kind, such
as a `ZonedDateTime` for a date period.
