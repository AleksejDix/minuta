Binds the interval functions to your units: `merge` and `snap` get the
units filled in, and the five that need none come along unchanged, so all
of them are on one object.

```ts
import { intervals } from "@aleksejdix/minuta/intervals";
```

```ts
intervals(units);
```

## Example

```ts
import { createUnits } from "@aleksejdix/minuta/core";
import { intervals } from "@aleksejdix/minuta/intervals";
import { divide, period } from "@aleksejdix/minuta";

const edit = intervals(createUnits());

const days = divide(
  period(Temporal.PlainDate.from("2026-03-01"), "month"),
  "day"
);
edit.merge(days, "month"); // → March, unit "month"
edit.snap(
  Temporal.ZonedDateTime.from("2026-03-15T10:37[Europe/Zurich]"),
  "minute",
  { step: 15 }
); // → 10:30
```

| Member   | Bound call                         | The same as                                               |
| -------- | ---------------------------------- | --------------------------------------------------------- |
| `clamp`  | `edit.clamp(period, bounds)`       | [`clamp(period, bounds)`](../clamp/)                      |
| `gap`    | `edit.gap(from, to)`               | [`gap(from, to)`](../gap/)                                |
| `merge`  | `edit.merge(periods, unit?)`       | [`mergeWith(units, periods, unit?)`](../merge-with/)      |
| `move`   | `edit.move(period, start)`         | [`move(period, start)`](../move/)                         |
| `resize` | `edit.resize(period, edge, value)` | [`resize(period, edge, value)`](../resize/)               |
| `snap`   | `edit.snap(value, unit, options?)` | [`snapWith(units, value, unit, options?)`](../snap-with/) |
| `split`  | `edit.split(period, at)`           | [`split(period, at)`](../split/)                          |

`snap` keeps its types bound: a `PlainDate` snaps to date units and gives a
`PlainDate`, a `ZonedDateTime` gives a `ZonedDateTime`.

## Parameters

| Name    | What it is                                                                             |
| ------- | -------------------------------------------------------------------------------------- |
| `units` | The units to compute with, usually [`createUnits()`](../../minuta-core/create-units/). |

## Returns

An object of the seven functions above, without a `units` argument.
