<section class="almanac-strip not-content">
  <div class="almanac-strip__text">
    <p class="almanac-eyebrow">Three lines</p>
    <h2>Every month, cut into its real weeks.</h2>
    <p>
      Edge weeks are clipped to the month and marked <code>custom</code>.
      Months of 28 to 31 days, leap years and clock changes are already
      handled.
    </p>
    <SiteLink class="almanac-link" to="concepts/periods-and-units/">How periods work →</SiteLink>
  </div>
  <div class="almanac-code">

```ts
import { divide, period } from "minuta";

const march = period(new Date(2026, 2, 1), "month");
divide(march, "week");

// → Mar 1          custom
//   Mar 2  – 8     week
//   Mar 9  – 15    week
//   Mar 16 – 22    week
//   Mar 23 – 29    week
//   Mar 30 – 31    custom
```

  </div>
