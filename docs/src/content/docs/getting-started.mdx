This page walks through the core idea in five small steps. Install minuta
first:

```sh
npm install @aleksejdix/minuta
```

minuta computes with Temporal. Chrome and Edge 144+, Firefox 139+ and
Node 26+ have it. Only where it is missing (Safari, Node 24), also install
`temporal-polyfill` and await `temporalReady()` once, before you compute:

```ts
import { temporalReady } from "@aleksejdix/minuta/temporal";

await temporalReady();
```

All examples run in Europe/Zurich, with weeks starting on Monday. The
results are shown as comments.

## 1. Create a period

A period is a stretch of time around a date, in a unit. Ask for the month
around October 12:

```ts
import { month } from "@aleksejdix/minuta";

const today = Temporal.ZonedDateTime.from("2026-10-12T14:30[Europe/Zurich]");
const october = month(today);
// → { start: 2026-10-01, end: 2026-11-01, unit: "month" }
```

Name the result after what it holds, `october` here: `const month = month(today)`
cannot work, `month` is already the function.

The time of day doesn't matter: any date in October gives the same month. A
month is made of `Temporal.PlainDate`s. The `start` belongs to it, the `end`
does not: the month ends where November starts.

## 2. Split it

`divide` cuts a period into smaller ones. A month into days:

```ts
import { divide } from "@aleksejdix/minuta";

const days = divide(october, "day");
// → 31 day periods: Oct 1, Oct 2, … Oct 31
```

Split into weeks and the edges are cut to fit the month. Those pieces get the
unit `"custom"`, because they are not whole weeks:

```ts
divide(october, "week");
// → Oct 1–4    "custom"  (the week started in September)
//   Oct 5–11   "week"
//   Oct 12–18  "week"
//   Oct 19–25  "week"
//   Oct 26–31  "custom"  (the week ends in November)
```

## 3. Step through time

`next` and `previous` move to the neighbouring period of the same unit:

```ts
import { next, previous } from "@aleksejdix/minuta";

next(october); //     → November 2026: { start: 2026-11-01, end: 2026-12-01 }
previous(october); // → September 2026
```

No arithmetic on days: months of 28, 30 or 31 days, years with leap days and
clock changes are handled for you.

## 4. Ask questions

```ts
import { contains, count, day, equals, month } from "@aleksejdix/minuta";

contains(october, today); //                                 → true
contains(october, Temporal.PlainDate.from("2026-11-01")); // → false, the end

count(october, "day"); //                                    → 31
count(day(today), "hour"); //                                → 24

equals(month(today), month(Temporal.PlainDate.from("2026-10-30")));
// → true: both days are in October
```

## 5. Label it

`toLocaleString` writes a period the way the locale reads it:

```ts
import { day, toLocaleString } from "@aleksejdix/minuta";

toLocaleString(october, "en-US"); //    → "October 2026"
toLocaleString(october, "de-CH"); //    → "Oktober 2026"
toLocaleString(day(today), "en-US"); // → "October 12, 2026"
```
